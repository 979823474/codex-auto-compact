# Codex Auto Compact v0.1.0

The first public release: a local Windows compression tool with an optional Codex skill plugin.

## Download and run

1. Download **CodexAutoCompact-v0.1.0.zip** from the assets below and extract the whole folder.
2. Double-click **打开工具.cmd**. Choose **7** for settings and **8** to preview matching files.
3. Choose **3** to compress now, or run **安装自动压缩.cmd** to install the local scheduled task.

Requires Windows 10/11, an NTFS source volume, and Windows PowerShell 5.1. The current interface is in Simplified Chinese; the repository includes a full English README. No compilation, Python installation, API key, or recurring AI call is required for normal use.

## Included

- NTFS transparent compression that keeps original file paths and contents readable by local programs.
- A configurable interval (default 30 days), minimum/maximum file size, file age, and source folders.
- Optional ZIP or TAR.GZ backup copies, Fastest/Optimal levels, and a custom destination.
- Sample format comparison, scan preview, status, logs, and pause/resume controls.
- Windows Task Scheduler integration and a local Codex skill plugin.

## Sample result

One 64-file sample totaled 15,909,531 bytes (15.17 MiB). At Optimal level, ZIP produced 3,600,105 bytes (3.43 MiB; 77.37% smaller) in 0.464 s, and TAR.GZ produced 3,575,739 bytes (3.41 MiB; 77.52% smaller) in 0.420 s. Results vary by data and system conditions.

These are archive-copy measurements. Originals remain in place and copies use extra destination space; use NTFS transparent compression to reduce source-volume usage.

## Verification and limits

The Windows CI checks PowerShell syntax, package metadata, integration behavior, archive formats, and format comparison. Each ZIP entry is verified against the packaged source before delivery. Use the attached `.sha256` file to verify the downloaded ZIP:

```powershell
Get-FileHash .\CodexAutoCompact-v0.1.0.zip -Algorithm SHA256
```

This tool cannot compress ChatGPT's cloud Library. It does not delete originals or clean up old backups. Some Windows `tar.exe` builds have problems extracting non-ASCII names; use ZIP or a UTF-8-aware extractor. Plugin loading depends on the Codex client and should be checked in a new chat.
